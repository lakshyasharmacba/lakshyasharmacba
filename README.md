## 🏡 WanderLust

### 🌍 Full Stack Travel Listing Platform

WanderLust is a full-stack travel listing platform where users can explore destinations, create listings, upload images and share reviews.

### ✨ Features

- 🔐 User Authentication
- 👤 Authorization
- 🏠 Create Listings
- ✏️ Update Listings
- 🗑️ Delete Listings
- 🖼️ Image Uploads
- ⭐ Reviews & Ratings
- 🔒 Owner Authorization
- 🍪 Session Management
- 🗄️ MongoDB Database
- 📱 Responsive UI
- ☁️ Cloud Deployment
